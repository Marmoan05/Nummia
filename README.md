# Nummia 0.9

Nummia te ayuda a organizar tus finanzas personales desde Android. Registra ingresos y gastos, planifica pagos, controla presupuestos y consulta cómo evoluciona tu dinero.

![Icono de Nummia](app/src/main/ic_launcher-playstore.png)

## Descargar

Descarga [Nummia 0.9 para Android](app/release/app-release.apk) y abre el archivo en tu dispositivo para instalarlo. Puede que Android te pida permiso para instalar aplicaciones desde esa fuente. Requiere Android 8 (API 26) o posterior.

## Funciones

- Registra, busca, filtra, edita y elimina ingresos y gastos.
- Añade pagos únicos o recurrentes y configura recordatorios.
- Organiza gastos con límites semanales y mensuales.
- Consulta el saldo, los movimientos recientes y estadísticas por periodo y categoría.
- Personaliza la moneda y los colores de la aplicación.
- Al empezar a usar la app, configura el saldo inicial y tus preferencias.
- Consulta las novedades de las versiones y busca actualizaciones desde Ajustes.

Consulta la [guía de uso](GUIA_USUARIO.md) para más información. El [historial de cambios](CHANGELOG.md) resume las novedades de cada versión.

## Tus datos

Los datos se guardan en este dispositivo; no necesitas una cuenta y no se sincronizan con la nube. Al actualizar, tus datos se conservan. Una instalación nueva empieza sin movimientos ni pagos de ejemplo.
