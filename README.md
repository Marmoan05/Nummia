# Nummia 0.8

Nummia te ayuda a controlar tus finanzas personales desde Android. Registra ingresos, gastos y pagos pendientes, establece presupuestos y consulta estadísticas.

![Icono de Nummia](app/src/main/ic_launcher-playstore.png)

## Descargar e instalar

El APK de Nummia 0.8 se distribuirá como archivo adjunto a la GitHub Release, separado del código fuente.

1. Descarga el APK adjunto a la Release 0.8.
2. Abre el APK en tu dispositivo y confirma la instalación. Android puede pedirte permiso para instalar aplicaciones desde esa fuente.
3. Si Android lo solicita, permite las notificaciones para recibir avisos de pagos pendientes.

Requiere Android 8.0 (API 26) o posterior.

## Qué incluye

- Registro y búsqueda de ingresos y gastos.
- Historial con filtros y detalle de cada movimiento.
- Presupuestos semanales y mensuales.
- Pagos únicos o recurrentes y recordatorios locales configurables.
- Estadísticas y gráficos por periodos y categorías.
- Varias monedas y paletas de colores.

Consulta la [guía de uso](GUIA_USUARIO.md) para ver cómo utilizar cada sección. El historial de cambios está en [CHANGELOG.md](CHANGELOG.md).

## Tus datos

Los datos se guardan en el dispositivo y no requieren una cuenta ni se sincronizan con la nube. En una instalación nueva, la app empieza con saldo cero y sin movimientos, pagos ni presupuestos de ejemplo. Si actualizas una instalación existente, sus datos locales se conservan; borrar o desinstalar los datos de la app puede eliminarlos.
